# CarPi5 Custom 3D Models & Props Directory

Drop any 3D model files into this directory or onto a USB drive (e.g. in a /models folder):
- Supported formats: **.obj** (Wavefront), **.gltf**, **.glb**, **.vrm**
- Any accompanying texture files (.png, .jpg) or material files (.mtl) can be placed right beside the model.
- The CarPi5 3D Room Customizer will automatically scan and list these props for interactive touch placement.
